Workspaces

The toolbar button and shortcuts only act when you press them, on the page you are on. Replace Notion's Copy link is off by default and is switched on per workspace. When on, copying a link on a public page of this workspace makes the extension check that the page is public (direct request to Notion, no cookies) and then ask ntn-link for the short link. Private pages are never sent to ntn-link.
