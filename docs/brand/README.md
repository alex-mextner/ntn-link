# Brand assets

- `fastp-logo.svg`: the owner's logo, traced from `fastp-logo-original.png` (`build.py`).
- `fastp-wordmark.svg`: "Fast Page" lettered as monoline marker strokes in the logo's hand.
- `fastp-lockup.svg`: logo + wordmark side by side, text baseline on the page's bottom edge.

All three use `currentColor`; set `color` on the element (or on a parent when inlined).

## Wordmark

Generated by `uv run docs/brand/wordmark.py` (standard library only; deterministic, fixed seed).
`--previews DIR` also renders light/dark PNGs at 1x/2x with headless Chrome for checking legibility.
The lettering is plain `<path>` with `fill="none"`, round caps and joins, and the logo's line weight
(40 units on the logo's 1254 px canvas; the original measures about 39.5 px, median of the skeleton
distance). The viewBox is the stroked outline plus one stroke of padding. No `<text>` and no font.

Licence: the letter shapes are original work authored in `wordmark.py` (centre lines, smoothed and
given a lean, wobble and per-letter drift in code). They are derived from no font or third-party
glyph data, so there is nothing to attribute: same licence as the repository (see `/LICENSE`).
`wordmark.test.ts` checks the SVGs parse, stay `currentColor` and font-free, and keep a sane aspect.
