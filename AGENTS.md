# Repository instructions

## Task tracking

Track ntn-link work in [GitHub Issues](https://github.com/alex-mextner/ntn-link/issues) using `task` from this repository. This is Ultra's personal project. Its tasks do not belong in the shared Tasks workspace at tasks.glide.vc.

Use the committed `task.yaml` routing. Do not override it with `--backend tasks` or a copied shared-workspace configuration. Keep existing descriptions, acceptance criteria, comments and evidence when migrating historical tasks.
